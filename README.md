# Huddle
*Less checking up. More checking in.*

## Overview

Huddle is an AI-powered family caregiving companion that helps older adults and their loved ones stay connected.

By handling medication reminders, keeping families informed through shared medication schedules, and providing daily wellness check-ins, Huddle helps reduce the need for constant health-related questions. Instead of turning every phone call into a checklist, families can focus on sharing life and staying connected.

## Features

- **Smart Medication Management:** Use Google Gemini AI to scan prescription labels, generate medication schedules, and track doses.
- **Voice-Based Wellness Check-ins:** Allow older adults to share how they're feeling through daily conversations with an AI companion.
- **AI-Powered Daily Digests:** Turn wellness check-ins into concise updates highlighting mood, needs, and potential health concerns while keeping personal conversations private.
- **Caregiver Alerts:** Flag missed medications, concerning symptoms, and urgent situations to keep families informed.
- **Connected Dashboards:** Provide dedicated interfaces for older adults and caregivers to view medication schedules and stay connected.

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **AI & Integrations:** Google Gemini API, Twilio

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/VanshikaTurkar/ruth-hackathon.git
cd ruth-hackathon
npm install
```

Configure your environment variables:

```bash
cp .env.example .env
```

Add your Gemini API key to `.env`. Twilio credentials are optional.

Run the application:

```bash
npm run dev
```
